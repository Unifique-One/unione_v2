## Additional scope caveats (not blockers)

- `pt/unione.md` is a visual mockup: example people, `@unifique.com.br` addresses and `unifique.com.br` URLs are illustrative and must not be copied literally into production content. Production hostnames are the `csphere.cloud` names listed in `inventory.md`.
- The mockup loads fonts from Google and icons from a public CDN. Any move to local/pinned assets must be confirmed for licensing and offline/resilience behaviour before deployment; this is a compatibility check, not permission to invent new visual assets.
- `api.csphere.cloud` appears in the requested hostname map but its existing record also points to an absent tunnel UUID. Treat it as pre-existing and restricted: no visual branding is expected and no repointing is authorized by this package.
- The reverse proxy is **Traefik**, not Caddy. No Caddy container, configuration, route or documentation reference is part of this stack; do not introduce one. The request path is cloudflared tunnel → Traefik → service.
- **Strict scope rule: only `csphere.cloud` may be altered.** No other domain, zone, DNS record or tunnel is changed. Inside `csphere.cloud`, the preserved records and the 17 unrelated tunnels remain untouched (E-04, E-05).

## Closure criteria

An exception is closed only when the required decision/action is recorded here with a date and the affected item has been re-validated in `validation.md`. E-01 met this on **2026-11-27** with the official favicon set from `https://unifique.com.br/`; the other entries remain open. Do not silently substitute a default: no invented favicon (the canonical set is official, not derived), no guessed mail settings, no assumed AI model or Ollama backend, no Caddy proxy, no changes outside `csphere.cloud`, no changes to preserved records or unrelated tunnels, and no plaintext token in documentation.
